# Интернет-магазин: Базовые сущности (E-commerce Core)

Проект представляет собой ядро для интернет-магазина, реализованное на Python с использованием ООП. Содержит основные сущности: товары (`Product`) и категории (`Category`).

## Зачем это нужно?
- **ООП-практика**: Учимся проектировать классы и работать с объектами в реальном контексте.
- **E-commerce основа**: Готовый модуль можно интегрировать в любой интерфейс (сайт, Telegram-бот, мобильное приложение).
- **Подготовка к масштабированию**: В будущем легко добавить корзину, платежи и аналитику.

### 2. Категория (`Category`)

## Тестирование
Запуск тестов:
```
pytest tests/
```
Фикстуры:
- `products()`  — возвращает тестовый набор товаров.
- `category()` — создает категорию на основе фикстуры `products()`
